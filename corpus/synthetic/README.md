# Synthetic invoices

Generated by `scripts/corpus/make-synthetic.ts` (deterministic). Fictional companies and people; the `.example` domains and IBANs are not real accounts. Licence: MIT, same as the repository.

- `xml/`: XRechnung 3.0 CII (ground truth)
- `hybrid/`: visible invoice plus embedded `factur-x.xml` (ZUGFeRD-style hybrid for testing, not a certified PDF/A-3)
- `plain/`: the same visible invoice without XML (Convert input)
